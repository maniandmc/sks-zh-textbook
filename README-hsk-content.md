# HSK 5급 독해 문제 입력 가이드

`hsk-reading.html`에서 **교사 계정으로 로그인 → 클래스 선택 → 단원 선택 → 편집**
화면에 들어가면 문제를 등록할 수 있습니다. 이 문서는 그 화면에서 각 칸에
무엇을, 어떤 형식으로 적어야 하는지 정리한 것입니다.

## 전체 구조

```
클래스
 └─ 단원 (예: "1단원")
     ├─ 제1부분 — 단어 빈칸 고르기 (46~60번)
     │    └─ 그룹 (지문 묶음, 예: "46-48")
     │         └─ 문제 (46, 47, 48 ... 각각 보기 A~D)
     ├─ 제2부분 — 내용일치 (61~70번)
     │    └─ 그룹 (지문 1개 = 문제 1개, 예: "61")
     │         └─ 문제 (보기 A~D)
     └─ 제3부분 — 독해 (71~90번)
          └─ 그룹 (긴 지문 + 삽화(선택), 예: "71-74")
               └─ 문제 4개 (각각 지시문 + 보기 A~D)
```

단원을 만들면 이 3부분이 항상 고정으로 먼저 보입니다. **각 부분 아래에 있는
"+ OO에 그룹 추가" 버튼으로 그 부분 안에 그룹을 넣고, 그룹 카드 안의
"+ 문제 추가"로 문제를 넣는 순서**입니다. 그룹을 먼저 만들지 않으면 문제를
넣을 수 없습니다.

---

## 제1부분 — 단어 빈칸 고르기

지문 하나에 빈칸이 여러 개 뚫려 있고, 빈칸마다 보기 A~D 중 하나를 고르는 형식입니다.

**그룹 추가 시:**
- **문제 번호**: `46-48` 처럼 그 그룹에 포함된 문제 번호 범위를 적습니다.
- **지문**: 빈칸이 들어갈 자리에 **`{번호}`** 를 그대로 적습니다. 화면에는 그
  번호가 적힌 밑줄로 바뀌어 나옵니다.

  ```
  随着智能手机的普及，越来越多的人{46}低头看手机。专家提醒，长时间保持这种
  姿势会给颈椎带来很大的负担，甚至{47}视力。因此，我们应该{48}使用手机的
  时间，多花时间进行户外运动。
  ```

**문제 추가 시** (그룹당 보통 3개, 번호는 지문의 `{46}{47}{48}`과 반드시 일치해야 함):
- **문제 번호**: `46`
- **문항 지시문**: 제1부분은 보통 비워둡니다.
- **보기 A~D**: 짧은 단어/구를 넣습니다 (예: 习惯 / 假装 / 结束 / 避免).

> 보기 중 하나라도 6글자를 넘으면 화면에서 자동으로 4칸 배열 대신 2칸
> 배열로 바뀝니다. 별도로 설정할 필요 없습니다.

---

## 제2부분 — 내용일치

짧은 지문 하나를 읽고, 그 내용과 일치하는 보기를 고르는 형식입니다.
**그룹 1개 = 문제 1개**라서 제1/3부분과 다르게 그룹마다 문제를 하나만 넣습니다.

**그룹 추가 시:**
- **문제 번호**: `61` 처럼 숫자 하나만 적습니다 (범위 아님).
- **지문**: 짧은 단락 (빈칸 없음, `{ }` 표시 필요 없음).

**문제 추가 시** (이 그룹에 딱 1개만):
- **문제 번호**: `61`
- **문항 지시문**: 비워둬도 되고, 필요하면 "다음 중 내용과 일치하는 것은?" 같은
  문구를 넣어도 됩니다.
- **보기 A~D**: 지문 내용과 일치/불일치하는 문장 4개.

---

## 제3부분 — 독해

긴 지문 하나를 읽고 문제 여러 개(보통 4개)를 푸는 형식입니다. 삽화를 넣을 수 있는
유일한 부분입니다.

**그룹 추가 시:**
- **문제 번호**: `71-74` 처럼 범위로 적습니다.
- **지문**: 긴 글. **Enter로 줄을 나누면 그 부분이 새 문단으로 분리되고, 각
  문단 첫 줄이 자동으로 들여쓰기됩니다.** 문단을 나눌 필요가 없으면 한 번에
  이어서 써도 됩니다.
- **삽화 이미지 URL** (선택): 인터넷에 이미 올라가 있는 이미지 주소를 붙여넣습니다.
  파일 업로드 기능은 없으므로, 이미지를 먼저 어딘가(예: 이미지 호스팅 서비스)에
  올리고 그 주소(`https://...`)를 넣어야 합니다. 비워두면 삽화 없이 지문만 나옵니다.

**문제 추가 시** (지문당 보통 4개):
- **문제 번호**: `71`
- **문항 지시문**: 이 부분은 필수입니다 (예: "根据第一段，可以知道张明年轻时：").
- **보기 A~D**: 문장 단위 보기. 길이와 상관없이 항상 2칸×2줄로 배열됩니다.

---

## 공통 규칙

- **굵게 표시**: 지문이나 문항 지시문, 보기 안에서 `**이렇게**` 감싸면 화면에
  굵게 나옵니다. (예: `下列**不属于**上文内容的是：`)
- **보기는 항상 A~D 4개를 채우고, 정답 라디오 버튼도 하나 선택해야** 저장됩니다.
  하나라도 빠지면 저장이 안 되고 오류 메시지가 뜹니다.
- **문제 번호와 지문 빈칸 번호를 맞추는 건 사람이 직접 확인해야 합니다** — 시스템이
  자동으로 검사해주지 않습니다. 제1부분에서 지문에는 `{46}`을 써놓고 문제 번호를
  `47`로 잘못 넣으면, 지문의 빈칸에는 46이 표시되고 그 아래 문제 목록에는 47이
  나와서 서로 안 맞게 보입니다.
- **정답은 교사에게만 보입니다.** 편집 화면의 문제 목록에는 정답 옆에 체크(✓)
  표시가 붙지만, 학생 화면("← 미리보기로"에서 보이는 시험지)과 학생 계정으로
  받는 데이터에는 정답이 아예 포함되지 않습니다. 다만 아직 정답을 바로 채점해
  주는 기능은 없고, 지금은 교사가 정답을 저장·확인하는 용도입니다.

## 등록 후 확인하는 법

편집 화면 위쪽의 **"← 미리보기로"** 를 누르면 학생에게 실제로 보이는 시험지
화면 그대로 확인할 수 있습니다. 문제 번호, 빈칸 위치, 보기 배열이 이상하지
않은지 여기서 눈으로 한 번 확인하고 넘어가는 걸 권장합니다.

## AI로 사진 속 문제 옮겨 적기

실제 HSK 문제집을 찍은 사진이 있다면, 손으로 타이핑하는 대신 AI(예: Claude,
ChatGPT 등 사진을 읽을 수 있는 모델)에게 사진과 함께 아래 프롬프트를 그대로
붙여넣으세요. 이 문서의 형식에 맞춰서 정리해달라는 내용입니다. AI가 정리해준
결과를 그대로 각 칸(문제 번호/지문/문항 지시문/보기 A~D)에 옮기기만 하면 됩니다.

```
너는 지금부터 HSK 5급 독해 문제 사진을 보고, 우리 학습 사이트에 입력할 수
있는 형식으로 옮겨 적는 역할이야. 아래 규칙을 반드시 지켜줘.

1. 먼저 이 문제가 아래 셋 중 어디에 해당하는지 판단해줘.
   - 제1부분(단어 빈칸 고르기): 한 지문 안에 빈칸이 여러 개 뚫려 있고,
     빈칸마다 보기 A~D 중 하나를 고르는 형식
   - 제2부분(내용일치): 짧은 지문 하나 + 그 내용과 일치하는 보기를 고르는
     문제가 1개
   - 제3부분(독해): 긴 지문 하나 + 문제 여러 개(보통 4개), 삽화가 있을 수 있음

2. "문제 번호"를 적어줘. 제1/3부분은 범위(예: 46-48, 71-74), 제2부분은
   숫자 하나(예: 61)로.

3. 지문 전체를 사진에 있는 그대로, 한 글자도 빠뜨리거나 바꾸지 말고 중국어
   원문 그대로 옮겨 적어줘. 절대 번역하거나 요약하지 마. 이때:
   - 빈칸(밑줄이나 ___로 표시된 부분)은 그 자리의 문제 번호를 넣어서
     {46} 처럼 중괄호로 표시해줘.
   - 원문에 굵은 글씨가 있으면 **그 부분**처럼 별표 두 개로 감싸줘.
   - 문단이 나뉘어 있으면 그대로 줄바꿈해서 구분해줘.

4. 문제마다 아래 형식으로 정리해줘:
   문제 번호:
   문항 지시문 (있으면 그대로, 없으면 "없음"):
   A:
   B:
   C:
   D:
   정답: (사진에 정답이 표시돼 있으면 A~D 중 어느 것인지. 안 보이면 "표시 안 됨")

5. 제3부분이고 사진에 삽화(그림/사진)가 있으면 "삽화 있음 (내용: ○○)"이라고
   알려줘. 이미지 파일 자체는 네가 만들 수 없으니, 실제 등록할 때는 그
   이미지를 어딘가에 올리고 그 주소(URL)를 넣어야 한다는 것도 같이 알려줘.

6. 글자가 흐릿하거나 확실하지 않은 부분은 추측해서 채우지 말고
   "확인 필요: ○○ 부분"이라고 표시해줘.

출력은 아래 틀을 그대로 사용해줘:

---
부분:
문제 번호:
지문:
(여기에 지문)

문제 [번호]
지시문:
A:
B:
C:
D:
정답:

문제 [번호]
...
---
```

> AI가 한자를 잘못 읽거나(OCR 오류) 빈칸 번호를 헷갈리는 경우가 있으니,
> 옮겨 적은 내용을 원본 사진과 한 번 대조해보고 등록하는 걸 권장합니다.
