# HSK 5급 독해 문제 입력 가이드

`hsk-reading.html`에서 **교사 계정으로 로그인 → 클래스 선택 → 단원 선택 → 편집**
화면에 들어가면 문제를 등록할 수 있습니다. 이 문서는 그 화면에서 각 칸에
무엇을, 어떤 형식으로 적어야 하는지 정리한 것입니다.

## 전체 구조

```
클래스
 └─ 단원 (예: "1단원")
     ├─ 제1부분 — 단어 빈칸 고르기 (46~60번)
     │    └─ 그룹 (지문 묶음, 예: "46-48")
     │         └─ 문제 (46, 47, 48 ... 각각 보기 A~D)
     ├─ 제2부분 — 내용일치 (61~70번)
     │    └─ 그룹 (지문 1개 = 문제 1개, 예: "61")
     │         └─ 문제 (보기 A~D)
     └─ 제3부분 — 독해 (71~90번)
          └─ 그룹 (긴 지문 + 삽화(선택), 예: "71-74")
               └─ 문제 4개 (각각 지시문 + 보기 A~D)
```

단원을 만들면 이 3부분이 항상 고정으로 먼저 보입니다. **각 부분 아래에 있는
"+ OO에 그룹 추가" 버튼으로 그 부분 안에 그룹을 넣고, 그룹 카드 안의
"+ 문제 추가"로 문제를 넣는 순서**입니다. 그룹을 먼저 만들지 않으면 문제를
넣을 수 없습니다.

---

## 제1부분 — 단어 빈칸 고르기

지문 하나에 빈칸이 여러 개 뚫려 있고, 빈칸마다 보기 A~D 중 하나를 고르는 형식입니다.

**그룹 추가 시:**
- **문제 번호**: `46-48` 처럼 그 그룹에 포함된 문제 번호 범위를 적습니다.
- **지문**: 빈칸이 들어갈 자리에 **`{번호}`** 를 그대로 적습니다. 화면에는 그
  번호가 적힌 밑줄로 바뀌어 나옵니다.

  ```
  随着智能手机的普及，越来越多的人{46}低头看手机。专家提醒，长时间保持这种
  姿势会给颈椎带来很大的负担，甚至{47}视力。因此，我们应该{48}使用手机的
  时间，多花时间进行户外运动。
  ```

**문제 추가 시** (그룹당 보통 3개, 번호는 지문의 `{46}{47}{48}`과 반드시 일치해야 함):
- **문제 번호**: `46`
- **문항 지시문**: 제1부분은 보통 비워둡니다.
- **보기 A~D**: 짧은 단어/구를 넣습니다 (예: 习惯 / 假装 / 结束 / 避免).

> 보기 중 하나라도 6글자를 넘으면 화면에서 자동으로 4칸 배열 대신 2칸
> 배열로 바뀝니다. 별도로 설정할 필요 없습니다.

---

## 제2부분 — 내용일치

짧은 지문 하나를 읽고, 그 내용과 일치하는 보기를 고르는 형식입니다.
**그룹 1개 = 문제 1개**라서 제1/3부분과 다르게 그룹마다 문제를 하나만 넣습니다.

**그룹 추가 시:**
- **문제 번호**: `61` 처럼 숫자 하나만 적습니다 (범위 아님).
- **지문**: 짧은 단락 (빈칸 없음, `{ }` 표시 필요 없음).

**문제 추가 시** (이 그룹에 딱 1개만):
- **문제 번호**: `61`
- **문항 지시문**: 비워둬도 되고, 필요하면 "다음 중 내용과 일치하는 것은?" 같은
  문구를 넣어도 됩니다.
- **보기 A~D**: 지문 내용과 일치/불일치하는 문장 4개.

---

## 제3부분 — 독해

긴 지문 하나를 읽고 문제 여러 개(보통 4개)를 푸는 형식입니다. 삽화를 넣을 수 있는
유일한 부분입니다.

**그룹 추가 시:**
- **문제 번호**: `71-74` 처럼 범위로 적습니다.
- **지문**: 긴 글. **Enter로 줄을 나누면 그 부분이 새 문단으로 분리되고, 각
  문단 첫 줄이 자동으로 들여쓰기됩니다.** 문단을 나눌 필요가 없으면 한 번에
  이어서 써도 됩니다.
- **삽화 이미지 URL** (선택): 인터넷에 이미 올라가 있는 이미지 주소를 붙여넣습니다.
  파일 업로드 기능은 없으므로, 이미지를 먼저 어딘가(예: 이미지 호스팅 서비스)에
  올리고 그 주소(`https://...`)를 넣어야 합니다. 비워두면 삽화 없이 지문만 나옵니다.

**문제 추가 시** (지문당 보통 4개):
- **문제 번호**: `71`
- **문항 지시문**: 이 부분은 필수입니다 (예: "根据第一段，可以知道张明年轻时：").
- **보기 A~D**: 문장 단위 보기. 길이와 상관없이 항상 2칸×2줄로 배열됩니다.

---

## 공통 규칙

- **굵게 표시**: 지문이나 문항 지시문, 보기 안에서 `**이렇게**` 감싸면 화면에
  굵게 나옵니다. (예: `下列**不属于**上文内容的是：`)
- **보기는 항상 A~D 4개**를 다 채워야 저장됩니다. 하나라도 비우면 저장이
  안 되고 오류 메시지가 뜹니다.
- **문제 번호와 지문 빈칸 번호를 맞추는 건 사람이 직접 확인해야 합니다** — 시스템이
  자동으로 검사해주지 않습니다. 제1부분에서 지문에는 `{46}`을 써놓고 문제 번호를
  `47`로 잘못 넣으면, 지문의 빈칸에는 46이 표시되고 그 아래 문제 목록에는 47이
  나와서 서로 안 맞게 보입니다.
- **정답 표시 기능은 없습니다.** 지금은 문제를 보여주는 화면만 만들어져 있고,
  어느 보기가 정답인지 저장하거나 채점하는 기능은 아직 없습니다.

## 등록 후 확인하는 법

편집 화면 위쪽의 **"← 미리보기로"** 를 누르면 학생에게 실제로 보이는 시험지
화면 그대로 확인할 수 있습니다. 문제 번호, 빈칸 위치, 보기 배열이 이상하지
않은지 여기서 눈으로 한 번 확인하고 넘어가는 걸 권장합니다.
