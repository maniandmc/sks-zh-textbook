# 교재(단원) 문장·단어 입력 가이드

`textbook.html`에서 **로그인 → (학생이면) 내 교재 / (교사면) 교재 관리 → 단원 선택**
화면에 들어가면 "문장" 탭에서 본문을 등록할 수 있습니다. 이 문서는 그중에서도
**"+ 여러 문장 한번에 추가"(문장 일괄 추가)** 화면에 본문을 어떻게 붙여넣어야
하는지, 그리고 AI에게 그 형식으로 정리해달라고 어떻게 요청하면 되는지 정리한
것입니다.

## 문장 일괄 추가 화면 규칙

화면에는 칸이 세 개 있습니다.

- **중국어** (한 줄에 한 문장)
- **병음** (한 줄에 한 문장)
- **한국어 번역** (한 줄에 한 문장)

**지켜야 할 규칙:**

1. **세 칸의 줄 수가 정확히 같아야 합니다.** 중국어 3줄이면 병음도 3줄,
   번역도 3줄이어야 합니다. 하나라도 다르면 "줄 수가 서로 다릅니다"라는
   오류가 뜨고 저장되지 않습니다.
2. **같은 줄 번호끼리 한 문장으로 묶입니다.** 즉 중국어 2번째 줄 + 병음
   2번째 줄 + 번역 2번째 줄이 하나의 문장이 됩니다. 한 문장이 중간에
   줄바꿈되어 두 줄로 나뉘면 그 뒤 모든 문장이 한 줄씩 밀려서 완전히
   어긋나 버리니, **문장 하나는 반드시 한 줄로만** 적어야 합니다.
3. **완전히 빈 줄은 자동으로 무시됩니다.** 세 칸 사이에 빈 줄 개수가
   달라도 상관없이 내용이 있는 줄만 세어서 순서대로 짝을 맞춥니다 (다만
   안전하게 세 칸 모두 빈 줄 없이 붙여넣는 걸 권장합니다).
4. 문장 앞뒤 공백은 자동으로 제거되니 신경 쓰지 않아도 됩니다.

**예시 (스크린샷 기준):**

```
[중국어]
中国人非常重视家庭。
家庭观念在中国文化中很重要。

[병음]
Zhōngguórén fēicháng zhòngshì jiātíng.
Jiātíng guānniàn zài Zhōngguó wénhuà zhōng hěn zhòngyào.

[한국어 번역]
중국인은 가족을 매우 중요하게 생각한다.
가족관념은 중국 문화에서 매우 중요하다.
```

각 칸이 2줄씩이므로 문장 2개가 만들어집니다.

## AI로 본문 정리해서 붙여넣기

교과서를 찍은 사진이나 그냥 중국어 지문 텍스트가 있다면, 한 문장씩 직접
나누고 병음·번역을 달지 않아도 됩니다. AI(Claude, ChatGPT 등)에게 아래
프롬프트를 사진 또는 텍스트와 함께 그대로 주면, 이 화면에 바로 붙여넣을 수
있는 형태로 정리해 줍니다.

```
너는 지금부터 중국어 지문을 문장 단위로 나누고, 병음과 한국어 번역을 달아서
우리 학습 사이트의 "문장 일괄 추가" 화면에 붙여넣을 수 있는 형식으로
정리하는 역할이야. 아래 규칙을 반드시 지켜줘.

1. 지문을 마침표(。) · 물음표(？) · 느낌표(！) 기준으로 자연스러운
   문장 단위로 나눠줘. 원문을 요약하거나 생략하지 말고, 있는 그대로
   전부 옮겨야 해.

2. 문장 순서는 원문 순서 그대로 유지해줘.

3. 각 문장마다:
   - 중국어 원문 (간체, 원문 그대로)
   - 병음 (성조 표기 포함, 단어 사이 띄어쓰기)
   - 자연스러운 한국어 번역
   을 만들어줘.

4. 결과는 아래처럼 "중국어", "병음", "번역" 세 블록으로 나눠서 출력해줘.
   각 블록 안에서는 문장 하나당 한 줄만 쓰고, 절대 문장 중간에
   줄바꿈하지 마. 세 블록의 줄 수는 반드시 똑같아야 해.

===중국어===
(문장1)
(문장2)
...

===병음===
(문장1 병음)
(문장2 병음)
...

===번역===
(문장1 번역)
(문장2 번역)
...

5. 글자가 흐릿하거나 확실하지 않은 부분은 추측해서 채우지 말고 그 줄에
   "확인 필요"라고 표시해줘.
```

AI가 답을 주면 `===중국어===` ~ `===번역===` 사이의 내용만 각각 복사해서
화면의 중국어 / 병음 / 한국어 번역 칸에 붙여넣고 **"일괄 추가"** 를 누르면
됩니다.

> AI가 한자를 잘못 읽거나(OCR 오류) 문장을 잘못 나누는 경우가 있으니,
> 붙여넣기 전에 원본과 한 번 대조해보는 걸 권장합니다. 특히 세 블록의
> 줄 수가 정확히 같은지 먼저 확인하세요 — 하나라도 다르면 화면에서
> 바로 오류로 알려줍니다.

## (참고) 단어는 표로 붙여넣을 수도 있습니다

"단어" 탭의 **"표 붙여넣기로 일괄 추가"** 버튼을 쓰면, 엑셀/구글 시트에서
복사한 표를 그대로 붙여넣어 단어를 한 번에 등록할 수 있습니다.

- 열 순서: **단어 · 병음 · 품사 · 뜻 · 예문** (단어만 필수, 나머지는 비워도 됨)
- 첫 줄이 "단어/word/병음/pinyin" 같은 제목 줄이면 자동으로 인식해서 제외합니다.
- 붙여넣은 뒤 미리보기 화면에서 항목별로 체크·수정·삭제한 다음 등록합니다.

AI에게 단어 목록을 표로 만들어달라고 할 때는 아래처럼 요청하면 그대로
복사해서 엑셀/구글 시트에 붙였다가 다시 복사하거나, AI 답변을 직접
복사해서 붙여넣어도 됩니다 (AI가 탭으로 구분된 표를 만들어주면 바로 인식됩니다).

```
위 지문에 나온 단어 중 학습할 만한 단어를 뽑아서, 아래 다섯 개 열을
탭(Tab)으로 구분한 표로 만들어줘: 단어, 병음, 품사, 뜻, 예문
(예문은 그 단어가 들어간 원문 문장 그대로). 품사는 명사/동사/형용사/부사
등 한국어로 짧게 써줘.
```
