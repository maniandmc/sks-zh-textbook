# 중국어 온라인 교재

HTML5 · CSS3 · Vanilla JavaScript 프론트엔드 + Cloudflare Pages Functions · D1로 만든
반응형 중국어 디지털 교재입니다. 교사가 클래스를 만들고 학생 계정을 발급하면,
학생은 클래스 교재를 학습하거나 자기 개인 교재를 만들어 편집할 수 있습니다.

> **진행 상황**: 인증/클래스 API, 교재 CRUD·권한·복사·진도율·북마크 API, 그리고
> 프론트엔드 연동(로그인 화면, 클래스 화면, 권한별 편집 UI)까지 전부 완료되었습니다.
> 남은 건 실제 배포뿐입니다. 배포 방법은 `README-deploy.md`, API 명세는
> `README-api.md`를 참고하세요.

## 실행 방법 (로컬 개발)

이 앱은 정적 파일이 아니라 Cloudflare Pages Functions(백엔드 API) + D1(DB)이 있어야
로그인 화면 이후로 넘어갈 수 있습니다. `index.html`을 그냥 더블클릭해서 여는 방식은
동작하지 않습니다.

```bash
npm install                        # wrangler 설치
npm run db:migrate:local           # 로컬 D1에 테이블 생성

# 최초 교사 계정 만들기 (로컬 D1에)
node scripts/hash-password.js "원하는비밀번호"
npx wrangler d1 execute chinese-textbook-db --local --command \
  "INSERT INTO users (username, password_hash, role, display_name) VALUES ('teacher1', '<위에서 나온 해시>', 'teacher', '내이름');"

npm run dev                        # wrangler pages dev . 실행, http://localhost:8788
```

로그인 후 첫 화면(홈)은 비어 있는 게 정상입니다 — 사이드바 **"클래스"** 메뉴에서
클래스를 만들고, **"교재 관리"**에서 단원을 추가하면 됩니다. 학생 계정은 클래스 화면에서
교사가 발급합니다.

│   ├── app.js                 로그인·세션, 데이터 계층, 라우팅, 테마, 편집 모드, 진행률, 북마크, 전역 검색
│   ├── views.js                홈 화면, 북마크 화면
│   ├── editor-forms.js          문장/단어/문법/문제/단원 편집 폼 (관리자·인라인 편집 공용)

├── data/                     초기 샘플 콘텐츠(第一课 등)의 원본 JSON. 지금은 로드되지 않고

├── functions/                Cloudflare Pages Functions (백엔드 API) — 자세한 내용은 README-api.md
├── migrations/                D1 스키마 마이그레이션
├── scripts/                   교사 계정 시딩용 CLI 스크립트

## 콘텐츠 편집 — 두 가지 방법

**1) 학습 화면에서 바로 편집 (일상적으로 쓰는 방법)**

헤더의 연필 아이콘을 누르면 **편집 모드**가 켜집니다. 이 교재에 쓰기 권한이 있을 때만
(교사는 자기 담당 클래스 교재, 학생은 자기 개인 교재) 본문·단어·문법·문제 탭에서
그 자리에서 추가·수정·삭제할 수 있습니다. 권한이 없는 교재(다른 클래스 교재 등)를
편집 모드에서 보면 편집 버튼 대신 "읽기 전용" 안내만 표시됩니다.

**2) 교재 관리 화면 (교사 전용, 구조적으로 한눈에 보며 편집하고 싶을 때)**

사이드바의 **"교재 관리"** 메뉴에서는 단원 목록을 왼쪽에 두고 오른쪽에서 문장/단어/문법/문제를
표 형태로 관리할 수 있습니다. 단원 추가·정보 수정·삭제도 이 화면에서 합니다. 학생 계정에는
이 메뉴 자체가 보이지 않습니다 — 개인 교재 편집은 학습 화면의 인라인 편집으로 합니다.

**두 방법은 완전히 같은 데이터를 씁니다** — 학습 화면에서 편집한 내용이 교재 관리 화면에도,
그 반대도 즉시 반영됩니다.

## 저장 방식

- 교재 내용(문장/단어/문법/문제), 진도율, 북마크, 클래스, 계정 정보는 전부
  **Cloudflare D1(SQLite)에 저장**됩니다. 로그인만 하면 어느 브라우저·기기에서도
  같은 내용을 보고 편집할 수 있습니다.
- **브라우저의 localStorage에는 UI 환경설정만 남아 있습니다**: 다크모드, 병음/번역 표시
  토글, 편집 모드 on/off, 마지막으로 보던 단원(계정별로 구분). 이건 기기마다 달라도
  괜찮은 값이라 의도적으로 로컬에만 둡니다.
- 교재 관리 화면의 "이 단원 내보내기" / "전체 JSON 내보내기"는 현재 D1의 내용을
  백업용 JSON 파일로 다운로드하는 기능입니다 (가져오기 기능은 없음).

## 구현된 기능

- 반응형 3단 레이아웃 (PC: 사이드바+본문+정보패널 / 태블릿: 정보패널 숨김 / 모바일: 햄버거 메뉴)
- 로그인(교사/학생 계정), 클래스 생성·참여 코드 가입·학생 계정 발급
- 사이드바 단원 목록이 클래스별/개인 교재별로 그룹핑되어 표시(읽기 전용 교재는 자물쇠 표시)
- 본문 문장 클릭 → 병음·번역·듣기(TTS)·문장 저장
- 병음/번역 개별 토글, 전체 듣기
- 단어 탭(표/카드 반응형) + 단원 내 검색, 클릭 시 상세정보
- 사이트 전체 단어 검색 (중국어/병음/뜻/품사/단원, 성조 무시 검색 지원)
- 문법 카드, 인터랙티브 연습문제(정답 즉시 확인)
- 북마크(단어/문장), 학습 진행률(진도율 초기화 가능), 다크모드
- 학생이 클래스 교재를 "내 교재로 복사"해서 자기 방식대로 편집 가능(스냅샷 복사)
- 권한 기반 편집 UI(쓰기 권한 없는 교재는 편집 버튼 자체가 보이지 않음) + 교재 관리 교사 전용

## 참고 사항

- 문장 듣기(TTS)는 브라우저 내장 `speechSynthesis`(중국어 음성)를 사용합니다.
  브라우저/OS에 따라 중국어 음성 품질이나 지원 여부가 다를 수 있습니다.
- 현재 데이터는 프로토타입용 샘플(第一课 전체 + 第二·三课 소량)입니다. 실제 교재
  내용은 로그인 후 편집 모드나 교재 관리 화면으로 입력합니다.
